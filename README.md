# SnapSync 📸

A centralized Event & Media Management Platform built for clubs and societies to organize, store, and share media efficiently. Built with Next.js (App Router), TypeScript, and MongoDB.

## Features
- **Secure Authentication:** JWT-based login and user registration.
- **Role-Based Access Control (RBAC):** Strict permission handling across custom roles (`Admin`, `Photographer`, `Club Member`, `Viewer`).
- **Event Management:** Full CRUD capabilities to organize fests, workshops, and trips.
- **Advanced Filtering:** Sort and search events dynamically by name, category, or date.
